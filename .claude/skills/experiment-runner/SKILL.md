# Experiment Runner

## Notebook Conventions

Notebooks are numbered sequentially (01-41; new ones continue from 42) and are generated by an nbformat script, not edited cell by cell. Each notebook:
1. Starts with a markdown cell describing purpose and dependencies
2. Imports from `src/` with `sys.path.insert(0, '../src')`
3. Sets `GLOBAL_SEED = 42` via `from utils import set_global_seed, GLOBAL_SEED, DEVICE`
4. Defines `OUTPUT_DIR` and creates it with `mkdir(parents=True, exist_ok=True)`
5. Saves all results to JSON in the output directory
6. Loads every number it displays or quotes through `src/canonical.py` (add a loader for a new JSON; never type a result into a cell)
7. Ends with a summary markdown cell listing outputs and next steps

## Notebook Quality Standards

- NEVER use excessive print statements. Jupyter renders cell outputs natively.
- Use `pd.DataFrame` to display tabular results, not print-formatted ASCII tables.
- Every notebook with numerical results MUST have at least one matplotlib figure.
- Show data/figures FIRST, then interpret. Never print claims before showing results.
- Minimize prints to essential progress updates during long computations only.
- Save all figures to OUTPUT_DIR with `dpi=150, bbox_inches='tight'`.
- Use seaborn or matplotlib styles consistent with the paper (no default gray backgrounds).

## Data Pipeline

For any new dataset, follow this pattern:
1. Load raw data, filter to relevant genes
2. Normalize: `sc.pp.normalize_total(adata, target_sum=1e4)` then `sc.pp.log1p(adata)`
3. Store as AnnData with cluster/label column in `adata.obs`
4. Save to `data/{dataset}_processed.h5ad`

This normalization keeps the softmax+library_size decoder mechanism valid across datasets.

## Split Convention

85/15 train/unseen split. Save as JSON:
```python
{
    'forget_indices': [...],
    'retain_indices': [...],
    'unseen_indices': [...],
    'n_forget': N,
    'n_retain': N,
    'n_unseen': N,
    'description': 'Human-readable description'
}
```

## VAE Training

```python
config = {
    'input_dim': adata.n_vars,
    'hidden_dims': [1024, 512, 128],
    'latent_dim': 32,
    'likelihood': 'nb',  # uses MSE despite the name
    'dropout': 0.1,
    'use_layer_norm': True,
    'lr': 1e-4,
    'epochs': 100,
    'batch_size': 256,  # reduce for small datasets
    'kl_warmup_epochs': 20,
    'free_bits': 0.03,
    'seed': GLOBAL_SEED
}
```

## Unlearning Methods

All in `src/train_*.py`, accept `--data_path`, `--split_path`, `--baseline_checkpoint`, `--seed`, `--output_dir`. Every run starts from `outputs/p1/baseline/best_model.pt` (July 4) so `scripts/checkpoint_manifest.py` can record its parent. Run from the project root:
```bash
# Extra-gradient (ExtraAdam; 3 critics initialized from the pre-trained attackers, co-trained; 50 passes over retain)
PYTHONPATH=src python src/train_unlearn_extragradient.py \
    --data_path data/{dataset}_processed.h5ad \
    --split_path outputs/{dataset}/split_structured.json \
    --baseline_checkpoint outputs/{dataset}/baseline/best_model.pt \
    --attacker_paths outputs/p2/attackers/attacker_v1_seed42.pt outputs/p2/attackers/attacker_v2_seed43.pt outputs/p2/attackers/attacker_v3_seed44.pt \
    --lambda_privacy 10 --epochs 50 --seed 42 --output_dir outputs/{dataset}/eg_lambda10_seed42

# Fisher scrubbing (per-sample retain Fisher, cached; global per-step cap 1e-3; 10 retain fine-tune epochs)
PYTHONPATH=src python src/train_fisher_unlearn.py \
    --data_path data/{dataset}_processed.h5ad --split_path outputs/{dataset}/split_structured.json \
    --baseline_checkpoint outputs/{dataset}/baseline/best_model.pt \
    --max_step 0.001 --fisher_damping 0.1 --fisher_cache outputs/{dataset}/fisher_retain_cache.pt \
    --seed 42 --output_dir outputs/{dataset}/fisher_seed42
```
Multi-seed re-derivation of the PBMC families: `scripts/stage1_rederive.py` and `scripts/stage1b_rederive.py`; Tabula Muris: `scripts/run_tabula_muris_unlearning.py`; clean retrains: `scripts/retrain_clean.py`.

## Scoring a New Checkpoint

1. Add it to `checkpoint_map()` in `scripts/save_persample_scores.py` and to `PBMC_METHODS` in `src/canonical.py`.
2. `PYTHONPATH=src python scripts/save_persample_scores.py` (one CPU attacker for every checkpoint, in one pass), then `scripts/nested_bootstrap_all.py`.
3. `scripts/score_utility_all.py` for held-out utility, `scripts/attack_lr_reference.py` for the reference audit, `scripts/checkpoint_manifest.py` for provenance, `scripts/claims_audit.py` to regenerate the comparison tables.
4. Load the resulting numbers through `src/canonical.py` wherever they are shown.

## Checkpoint Format

```python
torch.save({
    'model_state_dict': model.state_dict(),
    'config': config,
    'epoch': epoch,
    'train_loss': loss
}, output_dir / 'best_model.pt')
```

Load with config filtering:
```python
ckpt = torch.load(path, map_location=device)
model_config = {k: v for k, v in ckpt['config'].items()
    if k in ['input_dim', 'latent_dim', 'hidden_dims', 'likelihood', 'dropout', 'use_layer_norm']}
model = VAE(**model_config)
model.load_state_dict(ckpt['model_state_dict'])
```
