## Overview

Nine post-hoc machine unlearning methods, two constructive approaches (training-time synthetic augmentation and representation alignment), DP-SGD, and a likelihood-targeted variant are evaluated on VAEs trained on gene-expression data across two modalities, scRNA-seq (PBMC-33k, Tabula Muris) and bulk RNA-seq (TCGA-BRCA). The forget sets are rare, biologically coherent subpopulations. Every model is scored by one membership inference attacker trained on the baseline model and by a reference-model likelihood-ratio audit, against five clean retrains that never saw the forget set or the matched negatives.

Four findings.

1. **Measurement.** Scoring a subpopulation forget set against held-out samples of other types reads how well the model fits the type, not membership. On Tabula Muris, TCGA-BRCA, and PBMC-33k cluster 12 a model retrained without the forget set scores as high as the baseline; on PBMC-68k it scores at the opposite extreme (AUC 0.01 against 0.97), because its retain set cannot teach it the type. Two things make an attacker's score meaningful. A reference retrained on exactly the retain split turns it into a comparison with a model that never saw the cells, and the same reference gives a likelihood-ratio audit of how much better the model fits the forget cells than a retrained model does (PBMC-33k cluster 13: transferred attacker 0.80 against 0.53; audit 0.996 against a retrained range of 0.17 to 0.83). Held-out cells of the forget type, which PBMC-68k was split to provide, turn the question into one about the individual cells; there a standardized refit finds a per-cell signal on the baseline (0.69 and 0.59 against 0.45 to 0.55 for the retrained models), and on standardized features a refit attacker separates the PBMC-33k megakaryocytes from their cross-type neighbours at 0.98 on the clean retrain as well as the baseline, so a chance score against cross-type negatives never certifies absence of signal.
2. **Unlearning without a utility cost is reachable, not reached at published budgets, and not verifiable.** Success is the adversary's question, whether the strongest attack available can separate the forget cells from cells the model never saw any better than on a retrained model, whether or not the model still represents the type. On PBMC-68k cluster 9 each method is compared with eight clean retrains on the same 107 forget and 71 held-out megakaryocytes (per-cell refit: baseline 0.683, retrains 0.472 to 0.538; a method passes when its paired difference's interval lies below half the baseline's excess, 0.084). SSD (+0.132), SCRUB (+0.086) and Fisher scrubbing (+0.088) stay significantly more identifiable than the retrained models; retain-only fine-tuning, gradient ascent and contrastive unlearning lower the signal but cannot be certified at that margin; extra-gradient, whose critics are an adversary that knows the members, makes the cells more identifiable than before (0.84 to 0.91). Only the retain fine-tune run for 200 epochs reaches the retrained level (+0.008, interval -0.062 to 0.080), with the type still known (forget medians 820 to 846 against 1,014 to 1,154) and baseline utility. On cluster 8 (302 + 201 cells) every method stays more identifiable than the retrained models. On PBMC-33k, where only the type can be asked about, no method at its published budget reaches the retrained models; a Fisher step sweep finds caps (2e-3 and 2.5e-3) that land on them on both instruments at the baseline's utility, under the same paired test against the retrained models, between one that does too little and one that does too much, and nothing a controller can observe separates them. What is missing is verifiability, not reach or utility.
3. **Mechanism of the fitted-as-before mode.** Forget and retain Fisher information overlap at every VAE layer (cosine 0.35 to 0.49, against 0.018 for a classifier's class-specific output weights), so the edit damages both sets and the retain fine-tune that repairs the retain set restores the forget set with it where the overlap reaches the decoder output (0.485 on PBMC-33k, phase audit 269.5 to 5,569 to 308); on PBMC-68k cluster 9 the decoder-output overlap is 0.020 and the Fisher scrub stays. Long retain-only fine-tuning erodes the memorized fit on a timescale set by what the retain set holds (about 200 epochs on PBMC-33k, ten on TCGA-BRCA, cells at the retrained level but type still known at 200 on PBMC-68k), and nothing observable marks the stopping point.
4. **Mechanism of the overshoot.** The target is the fit of a type the model does not know. A fine-tune given the retrained models' level lands in the audit's retrained range at full utility; given the level of held-out look-alikes, the only substitute a controller can observe, it lands far short. A mixture-of-Gaussians simulation reproduces both mechanisms with the rare component's support and forgotten fraction as knobs.
